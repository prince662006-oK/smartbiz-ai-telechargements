# SmartBiz AI — Téléchargements

Installateur officiel de **SmartBiz AI Desktop** pour Windows 10 et 11 (64 bits).

**[⬇ Télécharger la dernière version](https://github.com/prince662006-oK/smartbiz-ai-telechargements/releases/latest/download/SmartBiz-AI-Setup.exe)**

- Se connecte à votre compte SmartBiz en ligne : https://smartbiz-ai-production.up.railway.app
- Caisse hors ligne : les ventes sont gardées sur le PC et envoyées dès le retour d'Internet.
- Assistant IA local facultatif (Ollama, sur votre PC).

## Installation
1. Téléchargez `SmartBiz-AI-Setup.exe` et ouvrez-le.
2. Si Windows affiche « Windows a protégé votre ordinateur » (éditeur pas encore vérifié) : **Informations complémentaires**, puis **Exécuter quand même**.
3. Connectez-vous avec votre e-mail et votre mot de passe SmartBiz.

Chaque version publie l'empreinte SHA-256 du fichier, pour vérifier son intégrité :
`Get-FileHash SmartBiz-AI-Setup.exe -Algorithm SHA256` (PowerShell).

Ce dépôt ne contient que les installateurs ; le code source n'est pas public.
